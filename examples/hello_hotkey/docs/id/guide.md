# Hello Hotkey

Hello Hotkey menyapamu saat kamu menekan sebuah tombol. Ini contoh dari Hariku Developer SDK.

## Mendapat sapaan

Tekan Shift+H saat jendela Hariku sedang fokus. Hello Hotkey menyapamu.

Tekan Shift+H dua kali dengan cepat, dan ia juga menyebutkan jam sekarang.

Kamu juga bisa meminta Aruna: tekan Ctrl+Alt+Backspace, lalu ketik atau ucapkan "sapa aku".

## Tombol dan perintah

- Shift+H: "Sapa aku" (dua kali cepat: sekalian jamnya)

Pindahkan ke tombol lain, atau buat tombolnya bekerja saat kamu di program lain, di Pengaturan,
Pintasan Keyboard, di bawah Hello Hotkey.

## Privasi

Hello Hotkey tidak mengirim apa pun ke mana pun dan tidak menyimpan apa pun.
