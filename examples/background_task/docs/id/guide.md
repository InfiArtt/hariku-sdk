# Penghitung Folder

Penghitung Folder memberi tahu berapa banyak file di folder Dokumen kamu dan berapa besar
ruang yang dipakainya. Ini contoh dari Hariku Developer SDK.

## Menghitung file-filemu

Tekan Shift+J saat jendela Hariku sedang fokus, atau bilang ke Aruna "hitung file di folder
dokumenku". Penghitung Folder memberi tahu bahwa penghitungan dimulai, lalu menyebutkan
hasilnya kalau sudah selesai. Folder yang besar bisa makan waktu; sementara itu kamu tetap bisa
memakai Hariku.

Untuk berhenti sebelum selesai, tekan Shift+J lagi.

## Tombol dan perintah

- Shift+J: "Hitung file di folder Dokumenku" (sekali lagi: berhenti)

Pindahkan ke tombol lain di Pengaturan, Pintasan Keyboard, di bawah Folder Counter.

## Privasi

Penghitung Folder hanya membaca nama dan ukuran file-filemu, di komputermu. Ia tidak membuka
isinya, tidak menyimpan apa pun, dan tidak mengirim apa pun ke mana pun.
