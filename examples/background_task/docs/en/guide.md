# Folder Counter

Folder Counter tells you how many files are in your Documents folder and how much space they
take. It is an example from the Hariku Developer SDK.

## Counting your files

Press Shift+J while Hariku's window has the focus, or tell Aruna "count the files in my
documents folder". Folder Counter says it has started, and tells you the result when it's done.
A big folder can take a while; you can go on using Hariku meanwhile.

To stop before it's done, press Shift+J again.

## Keys and commands

- Shift+J: "Count the files in my Documents folder" (again: stop)

Give it another key in Preferences, Input Gestures, under Folder Counter.

## Privacy

Folder Counter only reads the names and sizes of your files, on your computer. It doesn't open
them, saves nothing, and sends nothing anywhere.
