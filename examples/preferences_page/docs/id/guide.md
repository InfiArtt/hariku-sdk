# Tujuan Harian

Tujuan Harian menyimpan tujuanmu hari ini dan menyebutkannya saat kamu minta. Ini contoh dari
Hariku Developer SDK.

## Menulis tujuanmu

Buka Pengaturan, Tujuan Harian, lalu ketik tujuanmu di "Tujuanmu hari ini:". Tekan OK untuk
menyimpannya.

Untuk langsung ke halaman itu, bilang ke Aruna "buka pengaturan tujuan harian".

## Mendengar tujuanmu

Tekan Shift+Y saat jendela Hariku sedang fokus, atau bilang ke Aruna "tujuanku hari ini".

## Pengaturan

Di Pengaturan, Tujuan Harian:

- "Tujuanmu hari ini:" adalah yang disebutkan Tujuan Harian, sampai 200 karakter.
- "Kalau masih ada ucapan lain:" memilih "Tunggu sampai selesai", atau "Potong ucapannya" supaya
  tujuanmu langsung terdengar.
- "Sebutkan tanggalnya dulu" membuka dengan tanggal hari ini.

## Tombol dan perintah

- Shift+Y: "Sebutkan tujuanku hari ini"
- Tanpa tombol: "Buka pengaturan Tujuan Harian"

Pindahkan ke tombol lain di Pengaturan, Pintasan Keyboard, di bawah Daily Goal.

## Privasi

Tujuanmu hanya disimpan di komputermu, di folder data Hariku. Tidak ada yang dikirim ke mana pun.
