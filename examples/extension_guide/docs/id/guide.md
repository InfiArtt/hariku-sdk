# Peribahasa

Peribahasa mengucapkan sebuah peribahasa lama saat kamu minta, dalam bahasa Indonesia atau
Inggris, sesuai bahasa Hariku. Ini contoh dari Hariku Developer SDK, dibuat untuk menunjukkan
cara sebuah ekstensi membawa panduannya sendiri: panduan ini. Butuh Hariku 2.11 atau yang lebih
baru.

## Mendengar peribahasa

Bilang ke Aruna "ucapkan sebuah peribahasa": tekan Ctrl+Alt+Backspace, lalu ketik atau
ucapkan. Setiap kali kamu mendapat satu dari lima peribahasa lama, dipilih acak.

## Membuka panduan ini

- Bantuan, Panduan ekstensi..., lalu pilih Peribahasa.
- Tombol Panduan di Pengelola Ekstensi, di tab Terpasang.
- Bilang ke Aruna "panduan peribahasa" atau "guide for proverbs".
- Bilang ke Aruna "buka panduan peribahasa".

Panduannya terbuka di peramban webmu. Dengan NVDA, tekan H untuk berpindah dari judul ke judul.

## Tombol dan perintah

- "Ucapkan sebuah peribahasa": tanpa tombol
- "Buka panduan Peribahasa": tanpa tombol

Beri tombol di Pengaturan, Pintasan Keyboard, di bawah Proverbs.

## Privasi

Peribahasa tidak mengirim apa pun ke mana pun dan tidak menyimpan apa pun.
